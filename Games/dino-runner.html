About This Game

Dino Runner is an endless runner game inspired by the classic. Jump over cacti, survive as long as you can, and watch the speed increase! The dino changes color as the game gets faster — Green → Yellow → Red → Blue. How far can you go?

How to Play

  1. 1 Press Space, Arrow Up, or tap the Jump button to jump over cacti.
  2. 2 Survive as long as possible — speed increases every 100 points.
  3. 3 Watch the dino change color as the game gets harder!
