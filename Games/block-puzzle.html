About Block Puzzle

Block Puzzle is an original puzzle game built for Zaberz! Select block pieces from below, then tap anywhere on the 8x8 grid to place them. Complete a full row or column to clear it and earn 100 points. Plan ahead — game ends when no more pieces fit!
